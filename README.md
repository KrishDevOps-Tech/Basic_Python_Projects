# Basic Python Projects 🚀

A collection of foundational, production-grade Python CLI utilities demonstrating core language features, robust system scripting, and defensive programming.

---

## 📂 Projects Overview

| File | Project | Key Concepts & Modules |
|---|---|---|
| `Calculator.py` | CLI Calculator | Arithmetic operations, user input parsing, error handling |
| `KBC_Game.py` | Quiz Engine | Data structures, control flow, scoring logic |
| `Water_Drink-Remainder.py` | Hydration Reminder | Timers, scheduled background loops, desktop alerts |
| `PDF-Merger.py` | PDF Merger | File handling, document parsing, binary I/O |
| `QR_Code-generator.py` | QR Code Tool | Image matrix generation (`qrcode`, `Pillow`) |
| `File-Organizer.py` | File Organizer | Defensive OS scripting, collision handling, O(1) reverse lookup (`os`, `shutil`) |
